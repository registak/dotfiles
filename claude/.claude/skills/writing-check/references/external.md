# 社外発信の書き方

`~/.claude/rules/japanese-writing.md` の共通のルールに加えて守る。

ニュースレター、ブログ、登壇資料、採用向けの資料の本文。

- 段落で書く。箇条書きを多用しない
- 話題を均等に割り振らない。関心のあるところに字数が偏ってよい
- 対比のためだけの段落を作らない
- 丸括弧、コロン、矢印を本文で多用しない。ただし消して文が不自然になるなら残す
- 書く前に同じ媒体の過去の号や記事を読み、語り口を合わせる
- 人物の考えは Slack の逐語、本人の文書、議事録から採り、どの文がどの出典かをファイル内コメントに残す
- 引用は原文どおりに載せる。読点・句点・「！」を足したり消したりしない
- 本人の言葉を地の文に言い換えるときは原文の語に寄せる。一人称の文を本人の言葉として作らない
- 並べた人物紹介は、語り手（三人称か一人称か）をそろえる
- 標語の見出しは、代表の言葉や締めなど資料全体で1〜2か所に絞る
- 社内の呼び方を出さない。戦略資料の言い回し、社内の略称、社内でだけ通じる顧客の呼び名は、読み手が使う語に直す
